# v1.1.0

在 v1.0.0 基础上增强触发开关、唤醒收尾与合并转发兼容性。

## 新增

- `trigger.interest.enabled`：兴趣判断开关，默认开启；关闭时 `interest` 策略退化为时间窗口，且不调用判断模型。
- `wake.final_reply_prompt`：唤醒会话最后一条回复的收尾提示词，可自定义，留空则不注入。提示在生成前通过 `[唤醒收尾提示]` 注入 system prompt，只调用一次 LLM。

## 修复

- 唤醒回复计数在 aiocqhttp 下按实际发送成功增加；模型忽略或发送失败不消耗次数，下一次仍会带收尾提示。
- 合并转发改为通过 OneBot `get_forward_msg` 拉取，兼容 `bot.call_action` 与 `event.call_api`。
- 合并转发渲染兼容 OneBot 的 `data.text`、`data.messages` 与嵌套节点结构。
- 合并转发获取失败或为空时输出占位文本并记录警告日志。

## 兼容性

- 配置向后兼容，新字段均有默认值。
- 仍支持 AstrBot `>=4.29,<5`。
