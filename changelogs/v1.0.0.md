# v1.0.0

首个正式版本。

## 核心能力

- 独立重写的 AstrBot 群聊社交插件，生成、知识库、第三方长期记忆与发送均走 AstrBot 管线。
- 自主回复、关键词/问句/概率触发、直接 @ / 回复机器人与可选唤醒会话。
- 每群同时只处理一个决策；非 @ 消息在忙碌时跳过，@ 消息等待。

## 触发策略

- `every_message`：硬门控通过后每条消息都进入决策。
- `rules`：关键词、问句或概率命中后进入决策。
- `window`：默认策略，距上次判断超过 `trigger.window_seconds`（默认 30 秒）才采样。
- `interest`：先用轻量判断模型输出 `YES` / `NO`，`YES` 才进入决策。
- 可选刷屏保护：指定群在 30 秒内达到阈值后暂停自主采样，静默一段时间后恢复。

## 决策格式

- `marker`（默认）：模型输出自然语言；空文本或包含 `<NO_RESPONSE>` 时忽略。
- `json`：支持 `action`、`reason`、`messages`、`confidence` 与可选历史引用 `quote`；解析失败或置信度不足按忽略处理。
- 直接 @ / 回复机器人通常使用普通请求；唤醒会话活跃时按唤醒决策处理。

## 唤醒会话

- 支持总时长 `duration_seconds`、空闲超时 `idle_timeout_seconds` 与最多成功回复次数 `max_replies`（默认 5，0 表示不限）。
- 只有实际发送成功的唤醒接话才增加计数；模型忽略、决策失败或发送失败不消耗次数。
- 支持私聊、管理员和指定群覆盖；管理员优先级最高。
- 会话状态保存在进程内存中，重启清零。

## 上下文与存储

- SQLite 最近历史，按聊天隔离；支持保留天数与保留条数清理。
- 首次启动且数据库为空时，自动导入旧 SpectreCore JSON 历史一次；损坏文件跳过并记录日志。
- 可选图片转述：决策请求先转述图片，再连同原图交给模型；带并发限制与 LRU 缓存。
- 可选合并转发解析：限制层数、条数、字符数与超时，失败时使用占位文本。
- 可选上下文摘要：历史条数达到阈值时调用指定或当前 provider，失败时回退原始历史。
- 支持人格注入与仅本次请求生效的附加提示词。

## 兼容性

- 使用 AstrBot 内置知识库，并通过通用 `on_llm_request` / `on_llm_response` 钩子与第三方插件协同。
- LivingMemory 作为通用钩子兼容性的验证目标；不包含其代码，也不与其内部实现耦合。
- 插件自身不保存长期记忆，只保存组装上下文所需的最近聊天历史。
- 支持 AstrBot `>=4.29,<5`。

## 指令

- `/ds help`：查看指令列表。
- `/ds history [n]`：查看当前聊天最近 `n` 条历史（管理员，范围 1–20）。
- `/ds reset [群号]`：清空当前聊天历史（管理员）。
- `/ds mute [分钟]` / `/ds unmute`：临时静音与恢复（管理员）。
- `/ds status`：查看插件运行状态。
